# DataClock

### Automated Personal Data Expiry Tracking

DataClock is an ML-powered personal data retention system that predicts whether personal data should be **Retained, Reviewed, or Expired** based on purpose, sensitivity, usage, age, and retention conditions.

## Key Features

- Personal data classification
- Purpose mapping
- ML-based retention prediction
- Retention risk scoring
- Expiry monitoring
- Privacy dashboard
- Audit logs
- Data anonymisation
- College event registration case study

## Technology Stack

- React + Vite
- Node.js + Express
- MongoDB
- Python + FastAPI
- Scikit-learn
- Tailwind CSS

## ML Models

- Logistic Regression
- Decision Tree
- Random Forest

The best-performing model is selected based on evaluation metrics such as Accuracy, Precision, Recall and F1-score.

## Architecture

React Frontend  
↓  
Node.js / Express Backend  
↓  
MongoDB + Python ML Service

## Project Purpose

DataClock addresses the problem of unnecessary personal-data retention by connecting data purpose, sensitivity, usage and age with intelligent retention decisions.

> Protect data when it matters. Expire it when it doesn't.
